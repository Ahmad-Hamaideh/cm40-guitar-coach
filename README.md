# مدرّب CM40

دورة جيتار كلاسيك من الصفر للاحتراف على Yamaha CM40: ٤٠ درس بالرسومات، ومدرّب بيعزف قدّامك إصبع إصبع لتقلّده، وأغاني فيروز وإيقاعات عربية.

موقع ثابت بدون أي build: افتح `index.html` وبيشتغل.

- `index.html`: الصفحة والتصميم
- `js/core.js`: الصوت، الكوردات، رسم الرقبة
- `js/svgs.js` و `js/svgs2.js`: الرسومات التوضيحية
- `js/widgets.js`: الأدوات التفاعلية (رقبة، لعبة النغمات، مدرج، تبديل كوردات)
- `js/coach.js`: المدرّب اللي بيعزف
- `js/data1.js` و `js/data2.js`: محتوى الدروس
- `js/app.js`: بناء الصفحة والتقدّم
